# Task25-Laravel Framework Basics

A simple research task to understand the Laravel framework, its MVC architecture,
request lifecycle, folder structure, and core concepts before building projects.

================================================================================

## Task Objectives

1. Do a simple research on the Laravel Framework — its general idea and how it works.
2. Understand what MVC Architecture (Model - View - Controller) means and how
   Laravel applies it.
3. Download Laravel 11 or newer and try creating a new project.
4. Watch or read about the Laravel Request Lifecycle (how a request travels
   inside Laravel until a response is returned).
5. After creating the project, open the folders and learn what each one does
   (folder structure).
6. Learn what Service Providers and Middleware are and what they are used for.
7. Get familiar with the .env file and how Laravel uses it to store project
   settings (like the database and APP_KEY).

================================================================================

## Research Topics

- Laravel Framework
- MVC Architecture
- Laravel Request Lifecycle
- Service Providers in Laravel
- Middleware in Laravel
